# Security policy

Please do not report a suspected vulnerability in a public GitHub issue.

Send a private report to `contactus@spaarxlab.com` with the subject
`Private security report` and include:

- the affected repository, version, commit, or URL;
- a clear description of the issue and its impact;
- reproduction steps or a minimal proof of concept;
- any known exposure of credentials, personal data, or customer data;
- a safe way to contact you for follow-up.

Do not access data that is not yours, disrupt a service, retain sensitive data,
or publish exploit details before a coordinated resolution.

Supported versions and response expectations are defined by each repository's
own current state. A repository without a stated supported version must not be
assumed to be deployed or production-supported.
